# СчетOn — формирование счетов

Laravel-приложение для учёта контрагентов и массовой генерации счетов PDF (оверлей на бланк) с выгрузкой ZIP.

## Что умеет

- Регистрация с подтверждением администратором (первый пользователь становится админом автоматически).
- Справочник контрагентов (ИНН 10/12 с контрольной суммой).
- Формирование счетов за выбранный месяц: все контрагенты или отмеченные на странице.
- Дата в счёте — последний день выбранного месяца, услуга — «сопровождение в {месяце}».
- История выпущенных счетов (номер, период, сумма).
- Превью PDF без сдвига нумерации.
- Админка: активация пользователей и роли.

Счета в PDF **не хранятся постоянно** — это ZIP во временной папке (скачать можно один раз). В БД остаётся журнал выпусков. Контрагенты в БД не затрагиваются генерацией.

## Стек

- PHP 8.2+, Laravel 12
- Blade, Bootstrap 5
- MySQL / SQLite
- PDF: TCPDF + FPDI (шаблон `storage/app/templates/pechat.pdf`)
- ZIP: PHP ZipArchive

## Установка

```bash
composer install
cp .env.example .env
php artisan key:generate
```

В `.env` задайте БД и:

```
APP_TIMEZONE=Europe/Moscow
APP_LOCALE=ru
```

Положите бланк и шрифты:

- `storage/app/templates/pechat.pdf`
- `storage/app/fonts/arial.ttf`
- `storage/app/fonts/arialbd.ttf` (необязательно)

```bash
php artisan migrate
php artisan serve
```

Планировщик (очистка нескачанных ZIP старше 24 часов):

```
php artisan invoices:cleanup-tmp
```

В cron: `* * * * * php artisan schedule:run`

## Нумерация

Стартовый номер задаётся на главной и хранится у пользователя (`users.check_number`). При формировании номера резервируются атомарно (транзакция + lock).
